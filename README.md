# Machine Learning-Based Detection of Pathogenic Variants and Candidate Biomarker Discovery in Alzheimer's Disease Using Whole-Exome Sequencing

An integrated bioinformatics and machine learning pipeline for the identification, classification, and prioritization of pathogenic variants and candidate genes associated with Alzheimer's disease (AD) using whole-exome sequencing (WES) data.

---

## Overview

Alzheimer's disease (AD) is a complex neurodegenerative disorder with substantial genetic contribution. Whole-exome sequencing (WES) enables the investigation of protein-coding variants that may contribute to disease susceptibility and progression. However, the large number of variants generated by WES makes functional annotation, pathogenicity assessment, and prioritization challenging.

This project develops an integrated computational workflow combining WES variant processing, ANNOVAR-based annotation, functional and population-frequency filtering, pathogenicity prediction features, and supervised machine learning to identify and prioritize potentially pathogenic variants associated with AD.

The workflow further incorporates model interpretation approaches to identify informative genomic features and prioritize candidate genes carrying pathogenic or likely pathogenic variants.

---

## Project Objectives

The main objectives of this project are to:

- Process and integrate WES variant data from multiple samples.
- Annotate genomic variants using established variant annotation resources.
- Apply population-frequency and functional-region filters to prioritize potentially relevant variants.
- Select informative genomic and in-silico pathogenicity prediction features.
- Develop supervised machine learning models for variant classification.
- Compare the performance of multiple machine learning algorithms.
- Interpret model predictions using feature-importance and SHAP-based approaches.
- Prioritize candidate genes containing pathogenic or likely pathogenic variants.
- Identify a set of high-confidence candidate genes for further investigation in Alzheimer's disease.

---

## Data

The study used publicly accessible whole-exome sequencing data obtained from the NCBI Sequence Read Archive (SRA), using the relevant WES study accession **PRJNA532465**.

The computational workflow included variant data from **111 samples**. Following variant calling and quality filtering, sample-level VCF and tabular variant files were retained as the publicly available input data for this repository.

The repository does not include the complete merged annotation dataset or all intermediate variant-level analysis tables.
